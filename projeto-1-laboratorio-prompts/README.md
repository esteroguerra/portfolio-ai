# Laboratório de prompts

## Objetivo
Comparar duas versões de um prompt para classificar mensagens fictícias de clientes de delivery.

## Como foi feito
Cada versão foi testada com as mesmas mensagens (`entradas.txt`).
Os resultados foram avaliados manualmente e registrados em `resultados.md`.

## Resultados
Veja `resultados.md`.

## Limitações
Teste manual, poucas mensagens, sem integração com API.
